# Changelog

## 0.1.2 — 2026-09-30

- установка через AI-агента: в README готовый текст для Claude, ChatGPT, Codex и других агентов, а `docs/AI-INSTALL.md` переписан как пошаговый протокол по реальному пути от покупки VPS до первого теста;
- исправлено: установщик записывал в `.env` домен-пример `dm.example.com` вместо домена владельца, из-за чего Caddy не мог получить HTTPS-сертификат;
- установщик принимает VPS с 1 vCPU и 2 ГБ RAM и на таком сервере сам добавляет постоянный файл подкачки 2 ГБ для сборки; порог свободного диска — 22 ГБ;
- инструкции по Meta уточнены: какие ID и секрет вставлять, что не нажимать в блоке маркеров, какие webhook-поля выключить, автозаполнение поля App Secret браузером и публикация приложения.

## 0.1.1 — 2026-08-22

- добавлена поддержка Ubuntu 26.04 LTS вместе с Ubuntu 24.04 LTS;
- установщик по-прежнему отклоняет другие дистрибутивы и неподдерживаемые версии Ubuntu;
- инструкции и release-команды обновлены для обеих поддерживаемых LTS-версий.

## 0.1.0 — 2026-08-22

Первый релиз `inst_dm`:

- полностью самостоятельная установка на зарубежный Ubuntu 24.04 VPS и собственный домен;
- обязательная сверка DNS A-записи с публичным IPv4 выбранного VPS;
- собственные пути `/opt/inst_dm`, `/var/backups/inst_dm`, service user, cookie, база, Docker project и systemd units;
- автоматический HTTPS через Caddy и закрытый от интернета PostgreSQL;
- генерация независимых admin/session/encryption/webhook/database secrets;
- ежедневные структурно проверенные backup, полная проверка восстановления в одноразовой БД и явный restore;
- обновление только по аннотированному release tag с backup, readiness check и rollback;
- отдельная read-only диагностика `scripts/doctor.sh`;
- инструкция от выбора VPS и DNS до Meta OAuth, webhooks и первого реального теста;
- удалены конфигурации, привязанные к инфраструктуре исходного сопровождающего и альтернативным хостинг-платформам;
- сохранена MIT-атрибуция исходного проекта `xvn3x/comment-to-dm`.
